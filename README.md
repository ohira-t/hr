# 採用管理システム

HR部の採用業務を効率的に管理するためのWebアプリケーションです。

## 機能

- **ダッシュボード**: 全体の採用状況を一目で把握
  - 業態別（就労継続支援・GH・訪問看護）の採用進捗
  - 新規/既存セグメント別の管理
  - 期限間近・長期対応中の案件アラート

- **案件一覧**: 全採用案件の詳細管理
  - フィルター機能（業態・セグメント・ステータス）
  - ソート機能（期限順・経過日数順・更新順・五十音順）
  - 媒体マトリックス表示

- **設定**: 採用目標数値の設定

## 技術スタック

- **フレームワーク**: Next.js 16 (App Router)
- **UI**: Tailwind CSS, shadcn/ui
- **チャート**: Recharts
- **テーブル**: TanStack Table
- **アイコン**: Lucide React

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番ビルド
npm run build
```

## さくらインターネットへのデプロイ

1. 静的ビルドを実行:
```bash
npm run build
```

2. `out` フォルダ内の全ファイルをサーバーにアップロード

3. `.htaccess` ファイルを作成（必要に応じて）:
```apache
# 404エラー時のリダイレクト
ErrorDocument 404 /404.html

# trailingSlashの設定
DirectorySlash On
```

## 業務ロジック

### セグメント判定
- **新規**: 開業予定日が未来、またはステータスが「未着手」
- **既存**: 開業済み、またはそれ以外

### 日付計算
- **経過日数**: 今日 - 引継日
- **残り日数**: 採用期日 - 今日
- **Slowバッジ**: 経過日数 > 30日
- **緊急表示**: 残り日数 ≤ 14日

### 業態マッピング
- **就労**: Ａ型、Ｂ型、就労継続支援
- **GH**: ＧＨ、グループホーム
- **看護**: 訪問看護ステーション、育み看護
